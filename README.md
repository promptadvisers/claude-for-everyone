# Claude for Everyone

Practice files and prompts for Mark Kashef’s Claude Cowork for Everyone workshop. The exercises use fictional examples.

[Download all files (.zip)](https://github.com/promptadvisers/claude-for-everyone/archive/refs/heads/main.zip) · [Workshop setup](START-HERE.md) · [All copyable prompts](PROMPTS.md)

## Lab 1 · Check two receipts

Download the [Tartine Bakery receipt](01-receipts/lab/2026-04-12_Tartine_Bakery.pdf) and the [Uber receipt](01-receipts/lab/2026-04-18_Uber.pdf). Attach both to a new Claude conversation and use the [Lab 1 prompt](PROMPTS.md#lab-1--check-two-receipts). Open your workbook and verify that it has two rows, the amounts match the PDFs, and the total uses a formula.

After trying it, compare with the [checked workbook](01-receipts/examples/receipts_check.xlsx) and [answer key](01-receipts/ANSWER-KEY.md).

## Lab 2 · Audit the draft brief

Download the [Support](02-synthesis/inputs/01-support.md), [Finance](02-synthesis/inputs/02-finance.md), and [Operations](02-synthesis/inputs/03-operations.md) reports and the [draft brief](02-synthesis/lab/flawed-brief.md). Attach all four files to a new Claude conversation and use the [Lab 2 prompt](PROMPTS.md#lab-2--audit-the-draft-brief). Open the source for each claim before accepting Claude's audit.

After trying it, compare with the [checked audit](02-synthesis/examples/checked-audit.md).

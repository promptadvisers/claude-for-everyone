# Getting real work done in Claude Desktop

Unzip this folder. Open this document first, then [PROMPTS.md](PROMPTS.md).

If you have the current unified Claude interface, start a New conversation. If your composer still has a Cowork selector, select Cowork for the file tasks. On the web, you can use the upload route where enabled. If your Free or managed account lacks a tool or reaches its limit, work from the supplied files and check the prepared result.

The full desktop walkthrough uses an updated Claude Desktop app on Mac or Windows and an eligible paid plan. You can follow the evidence checks without connecting work email, company drives or private folders.

1. **01-receipts.** Use the five PDFs in demo and the two PDFs in lab. Open the matching workbook in examples and check its formula against the [receipt answer key](01-receipts/ANSWER-KEY.md).
2. **02-synthesis.** Add the three notes in inputs to a project or attach them in one conversation. Use the draft in lab and compare with the audited brief in examples.
3. **03-sales.** Use the April CSV in inputs. Compare the three sample deliverables to the [April answer key](03-sales/ANSWER-KEY.md).
4. **04-repeat.** Review the practice notes and a sample schedule proposal. It shows the items to verify before an actual schedule runs.

5. **05-artifacts.** Start with the two Mission Control prompts. Open the [first build](05-artifacts/Mission-Control-Build.html) and the [edited version](05-artifacts/Mission-Control.html) in a browser if you want to try them without Claude. Select a planet, pause the orbits, and use Reset view.

Use fresh copies of the files to try an edit. Every example is fictional and designed for this workshop. The outputs give you a way to finish the same checks if the live tool is unavailable or takes longer than the class slot.
